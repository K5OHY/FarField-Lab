# HFTA engine hosting probe (temporary)

Checks whether the OpenHFTA terrain engine builds and gives the right numbers on Streamlit Community Cloud.
It is a separate test app, not part of FarField Lab, and will be deleted once the check is done.

Deploy on share.streamlit.io: repo `k5ohy/farfield-lab`, branch `beta`, main file `hfta_probe/streamlit_app.py`.
Its `packages.txt` and `requirements.txt` sit beside the entry file, so they only apply to this test app.
